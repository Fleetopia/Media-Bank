IMPORTANT:
Custom/premium emoji are controlled by Telegram custom emoji IDs.
Put the IDs in .env (EMOJI_NEW, EMOJI_OK, etc.).
If blank, normal emoji are used.

RUN:
1. Put your working .env in this folder.
2. Run START.bat.
3. Keep the window open while the bot is running.

AUTO REPORT TIME:
Configured in .env and uses the local time of the PC/server running the bot.
